State outlines generated from the Census-derived boundaries in `us-atlas/states-10m.json` using `scripts/generate-onboarding-state-outlines.mjs` (run from the repository root with Playwright available, or set PLAYWRIGHT_MODULE).

The outlines indicate geography only. No towns, stores, heatmaps, counts, or coverage percentages are inferred from these images. Coverage strength comes from the durable coverage contract, independently of transient collector health.
