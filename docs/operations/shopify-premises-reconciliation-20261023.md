## Minimal supplement for independent sources

The reviewed four-export Blob baseline is necessary but excludes two mutable authorities:

- `source_poll_jobs.projection.drops`: current accepted poll projections, with previous projection retained when a run fails. `sourceSchedulerHealth(false)` deliberately strips projections, returning counts/status only. Poll run rows retain accounting, not a complete archive of replaced projections.
- `source_lane_subjects` joined to `source_lane_heads`: the SC lane's current available/unavailable subjects. A negative overwrites the prior subject and may omit `sourceDrop`; retained closed `source_lane_opportunities` can contain earlier public premise identity. Lane batch metadata alone has no premise census.

See deployed [scheduler](https://github.com/tarsagent22/Bourbon-Signal/blob/e237c76e089dd9635013c33804ff443df1654440/src/lib/source-scheduler.ts), [poll schema](https://github.com/tarsagent22/Bourbon-Signal/blob/e237c76e089dd9635013c33804ff443df1654440/src/lib/source-scheduler-schema.sql), [lane schema](https://github.com/tarsagent22/Bourbon-Signal/blob/e237c76e089dd9635013c33804ff443df1654440/src/lib/source-lane-schema.sql) and [lane overlay](https://github.com/tarsagent22/Bourbon-Signal/blob/e237c76e089dd9635013c33804ff443df1654440/src/lib/source-lane.ts). Do not call normal overlay composition merely to obtain this baseline: its reads can write trace telemetry. Do not use broad repository `inspect()`/backup exports or export complete JSON payloads.
